五、项目介绍
项目编号：bs132B

系统面向爱心用户、救助志愿者和管理员。小程序提供动物浏览、救助线索提交、领养申请与回访反馈，志愿者处理救助、健康、寄养和初审任务；管理端维护动物档案、审核线索与申请并查看业务统计。

角色：爱心用户、救助志愿者、管理员

爱心用户功能：注册登录与个人资料维护、浏览筛选动物档案、收藏意向动物、提交救助线索、提交领养申请并查询进度、提交领养回访反馈。

救助志愿者功能：查看并认领救助任务、登记救助处置结果、维护动物档案与健康记录、管理寄养信息、初审领养申请材料、处理回访任务、查看个人任务。

管理员功能：查看救助与领养统计、管理用户与志愿者资料、审核救助线索、维护动物分类与档案、审核领养申请、分配并查看回访、发布平台公告。
